# Cloud Lite Browser (GitHub Codespaces)

این پروژه یک محیط مرورگر ابری سبک و آماده روی **GitHub Codespaces** را بدون نیاز به اجرای دستی دستورات ترمینال راه‌اندازی می‌کند.

## ساختار فایل‌ها

- **`.devcontainer/devcontainer.json`**: جایگزینی ایمیج سنگین ۱۱ گیگابایتی پیش‌فرض گیت‌هاب با ایمیج سبک `ubuntu-24.04`، فعال‌سازی Docker، اجرای خودکار پروژه هنگام بوت (`postStartCommand`) و باز کردن خودکار پورت `3000`.
- **`docker-compose.yml`**: تعریف کانتینر خالص `linuxserver/firefox` با تخصیص `1GB` حافظه اشتراکی (`shm_size`) و تنظیم منطقه زمانی تهران.

## نحوه استفاده

1. یک مخزن **Private** جدید در گیت‌هاب بسازید (مثلاً `cloud-lite-browser`) و فایل‌های داخل این زیپ را در آن آپلود یا Push کنید.
2. وارد صفحه مخزن شوید، روی دکمه سبز **Code** کلیک کنید و وارد تب **Codespaces** شوید.
3. *(اختیاری برای آی‌پی اروپا)* روی سه نقطه (`...`) بزنید، **New with options** را انتخاب کنید و **Region** را روی **Europe West** بگذارید.
4. پس از بالا آمدن محیط، کانتینر فایرفاکس به صورت خودکار اجرا شده و از بخش **Ports** روی پورت **3000** در دسترس است.
